# Phase 3A.2: Pydantic Schema Validation

**Completed:** February 22, 2026  
**Status:** ✅ COMPLETE

---

## Summary

Implemented type-safe Pydantic v2 schemas for all JSON artifacts generated by MLCLI commands, preventing silent data corruption and enabling reliable Meta-ML training.

---

## Problem Statement

JSON artifacts were being generated without validation:
- `data_profile.json` - No type checking
- `training_summary.json` - No field validation
- `evaluation_report.json` - No schema enforcement

This led to:
- Silent data corruption
- Meta-ML model training on invalid data
- Debugging difficulties
- No version migration support

---

## Solution

Created `mlcli/core/schemas/` package with Pydantic v2 models:

### 1. Base Schema (`base.py`)

```python
class VersionedArtifact(BaseModel):
    """Base class for all versioned MLCLI artifacts."""
    
    schema_version: str = "1.0.0"
    created_at: datetime
    mlcli_version: Optional[str]
    
    model_config = {"extra": "forbid"}
```

**Benefits:**
- Schema versioning for migration support
- Automatic timestamp tracking
- Prevents unknown fields (`extra="forbid"`)

### 2. Data Profile Schema (`data_profile.py`)

```python
class DataProfileSchema(VersionedArtifact):
    original_shape: tuple[int, int]
    processed_shape: Optional[tuple[int, int]]
    numeric_columns: List[str]
    categorical_columns: List[str]
    target_info: Optional[TargetInfo]
    quality_issues: Optional[QualityIssues]
    missing_values: Dict[str, int]
    missing_percentage: Dict[str, float]
    
    @property
    def n_samples(self) -> int: ...
    @property
    def missing_ratio(self) -> float: ...
    @property
    def has_quality_issues(self) -> bool: ...
```

**Features:**
- Nested models for complex structures
- Computed properties for convenience
- Field validators for shape constraints

### 3. Training Summary Schema (`training_summary.py`)

```python
class TrainingSummarySchema(VersionedArtifact):
    task_type: str  # classification | regression
    best_model_name: Optional[str]
    best_score: Optional[float]
    models_trained: int
    training_config: Optional[TrainingConfig]
    model_results: Dict[str, ModelResult]
    
    @property
    def model_ranking(self) -> List[tuple[str, float]]: ...
    @property
    def score_variance(self) -> float: ...
```

**Features:**
- Type-validated task type
- Model result dictionaries
- Ranking and variance computations

### 4. Evaluation Report Schema (`evaluation_report.py`)

```python
class EvaluationReportSchema(VersionedArtifact):
    task_type: str
    sample_size: int
    metrics: Dict[str, Any]
    confusion_matrix: Optional[List[List[int]]]
    
    @property
    def primary_metric(self) -> float: ...
    @property
    def performance_level(self) -> str: ...
    @property
    def precision_recall_gap(self) -> float: ...
```

**Features:**
- Task-specific metric handling
- Performance level interpretation
- Precision-recall gap calculation

## Usage Examples

### Loading and Validating

```python
from mlcli.core.schemas import (
    DataProfileSchema,
    TrainingSummarySchema,
    EvaluationReportSchema,
    load_and_validate,
)

# Load with validation
profile = load_and_validate(
    "data/processed/data_profile.json",
    DataProfileSchema
)

# Access typed properties
print(f"Samples: {profile.n_samples}")
print(f"Features: {profile.n_features}")
print(f"Missing ratio: {profile.missing_ratio:.2%}")

if profile.has_quality_issues:
    print("Quality issues found!")
    print(profile.quality_issues.high_missing_columns)
```

### In Meta-ML Feature Extraction

```python
def extract_features(profile_path: Path, eval_path: Path) -> np.ndarray:
    # Validated loading - no silent corruption
    profile = load_and_validate(profile_path, DataProfileSchema)
    evaluation = load_and_validate(eval_path, EvaluationReportSchema)
    
    return np.array([
        profile.n_samples,
        profile.n_features,
        profile.missing_ratio,
        evaluation.primary_metric,
        evaluation.precision_recall_gap,
        # ... more features
    ])
```

## API Reference

### Main Functions

```python
def load_and_validate(
    file_path: Union[str, Path],
    schema_class: Type[T],
    strict: bool = False
) -> T:
    """Load JSON file and validate against schema."""

def validate_dict(
    data: Dict[str, Any],
    schema_class: Type[T],
    strict: bool = False,
    source: Optional[str] = None
) -> T:
    """Validate dictionary against schema."""
```

### Error Handling

```python
from mlcli.core.schemas import SchemaValidationError

try:
    profile = load_and_validate(path, DataProfileSchema)
except SchemaValidationError as e:
    print(f"Validation failed: {e}")
    for error in e.errors:
        print(f"  {error['loc']}: {error['msg']}")
```

## Testing Recommendations

```python
# tests/test_schemas.py
import pytest
from mlcli.core.schemas import DataProfileSchema, SchemaValidationError

def test_valid_data_profile():
    data = {
        "original_shape": [1000, 10],
        "numeric_columns": ["age", "income"],
        "missing_values": {},
        "missing_percentage": {},
    }
    profile = DataProfileSchema(**data)
    assert profile.n_samples == 1000

def test_invalid_shape():
    data = {"original_shape": [1000]}  # Missing columns
    with pytest.raises(SchemaValidationError):
        DataProfileSchema(**data)

def test_unknown_field_rejected():
    data = {
        "original_shape": [1000, 10],
        "unknown_field": "value",  # Should fail
    }
    with pytest.raises(SchemaValidationError):
        DataProfileSchema(**data)
```
