HIGH RISK ITEMS:

  🔴 3A.2 (Pipeline Persistence)
     Risk: Breaking changes to predict command
     Mitigation: Write integration tests FIRST
     Fallback: Keep old predict logic with --no-pipeline flag

  🟡 3C.2 (Model Training)
     Risk: Model doesn't converge or has poor accuracy
     Mitigation: Start with simple baseline (Logistic Regression)
     Fallback: Use rule-based suggestions (already works)

  🟡 3D.1 (Suggest Command Refactor)
     Risk: Breaking existing functionality
     Mitigation: Keep old command as suggest_cmd_legacy.py
     Fallback: --engine=rules flag to use old logic

LOW RISK ITEMS:

  🟢 3A.1 (Schemas): Low risk, pure validation layer
  🟢 3A.4 (Telemetry): Optional, can ship without
  🟢 3B.1 (KB Gen): Synthetic data, can iterate
